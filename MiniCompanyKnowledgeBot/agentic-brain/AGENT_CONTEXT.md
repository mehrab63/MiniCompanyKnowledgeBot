# AGENT CONTEXT

این پروژه یک MVP از سیستم Knowledge Base داخلی شرکت است.

منبع داده:
docs/*.txt

منطق فعلی:

1. فایل‌ها خوانده می‌شوند.
2. سوال کاربر دریافت می‌شود.
3. فایل دارای بیشترین شباهت انتخاب می‌شود.
4. محتوای آن برگردانده می‌شود.

پیشنهاد توسعه:

- Vector Search
- OpenAI Embeddings
- Semantic Search
- Chunking
- Source Citation
